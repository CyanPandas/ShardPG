## 本轮实现与尚未开放的能力

本轮实现三项已确认的安全要求：PG 显式 xmin 冻结；回收启动线和停止分配线之间
保留间隔；页面和回收证书按崩溃恢复/副本能够认可的顺序持久化。

**本轮未启用 32 位 XID 从头循环分配。** 当前分配器、clog 寻址、后端终局缓存、
WAL 水位和部分恢复/供给路径仍依赖线性编号，原绝对上限停发保护保留。显式冻结
消除了长期存活行对旧普通 xmin 的依赖，但不能独自证明跨轮账本槽、迟到决议和缓存
不会混用。正式开启复用前，必须补齐这些路径的轮次或可靠失效协议、格式迁移，
以及缩小号空间的多轮回卷/崩溃/切主验收。不能只删除 HARD_LIMIT 或把 next_xid 改回 3。

## 1. 显式冻结

完整 sweep 对主堆和 TOAST 依次执行：

1. 消毒中止或 lock-only 的旧 xmax；
2. 删除中止插入的垃圾；
3. 删除安全的已提交删除版本，清索引后回收行指针；
4. 给保留的安全老行设置 PG `HEAP_XMIN_FROZEN`。

冻结保留原始 xmin 数字。MVCC、Self、Dirty、Update、ANALYZE 判定均读取
`HeapTupleHeaderGetXmin()`：冻结优先于自见性、活跃表、终局缓存和 clog。
冻结后的张三 xmin=100 不再查询普通事务 100；随后 DELETE/UPDATE 的 xmax 仍正常判定。
冻结使用内核 `heap_freeze_execute_prepared()` 产生 FREEZE_PAGE WAL，不由读者写标记。

手工 sweep 也重新计算安全前缀。取不到 GlobalSafeTs，或目标跨越 RUNNING、PREPARED、
空洞、`commit_ts=0` 或 `commit_ts >= GlobalSafeTs`，必须在改页面之前拒绝。
同一截断点的重试允许幂等执行。旧实现已隐式冻结的前缀由旧安全证书兼容解释，并在
下一趟 sweep 转换成显式冻结；这项兼容不能被当作跨轮复用证明。

## 2. 分配和回收阈值

目标环形协议按分配位置距离最老未安全回收位置的距离计算年龄，而非按 XID 的绝对大小。
本轮线性分配保持 `age = next_xid - clog_truncate_before`。

| 配置 | 默认值 | 约束 |
|---|---:|---|
| `pg_partdist.shard_vacuum_max_age` | 200000000 | 启动线必须低于停止线 |
| `pg_partdist.shard_xid_stop_age` | 2146483648 | 最大 2³¹−1000000，且必须高于启动线 |

每次领号前检查，包括跳过已有终局槽的每次迭代。批量持久化预留被截在停止线以内；
升主跳号若会越线则拒绝。停止仅限制该分片的新 XID 分配，回收仍能执行；安全边界推进
使年龄降低后可恢复写入。旧快照可以来自其他分片；PREPARED 不允许因压力而单方中止。

调低两条线时先降低启动线；调高时先提高停止线。配置校验发生在参数检查/生效时，
SIGHUP 后应通过 SHOW 确认。自定义自动启动器开关仍是运维停止后台清理的开关，
关闭后不允许绕过停发保护，手工清理入口仍可用。

## 3. 可恢复、可复制的完成事实

复制分片按以下顺序执行（本地未复制表省略多数派步骤）：

```
主堆/TOAST 冻结、清理、索引处理
  → 本机页面 WAL fsync
  → 排空捕获环，页面流达到持久多数派
  → 持久化页面趟完成标记 vx
  → 水位 CTRL fsync 并达到持久多数派
  → 持久化本机回收边界 tb
  → 删除旧 clog 整段
```

捕获丢失产生分叉标记时，不能继续为该分片签发完成证书。复制失败须传播错误，
不能降为 WARNING 后推进边界。失败后页面的非事务修改可能已保留，重试须幂等。

副本按分区流序应用冻结页面与 CTRL；checkpoint 必须先刷盘并 fsync 页面，再持久化
分片发号/回收水位，最后推进持久回放游标。水位只放共享内存会在崩溃时丢失，不能算
完成。旧证书重放不得使水位后退。升主必须完成既有追平/检查点流程后才能继续分配。

部署时先使所有可能接任的节点使用识别冻结标记的新版本，再执行新的 sweep。
旧版本的分片可见性直接读取 raw xmin，不能作为这项协议下的接任者。
